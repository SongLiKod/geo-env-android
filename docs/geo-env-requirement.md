# GeoEnv 需求规格说明书
应用名称：GeoEnv
仓库名称：geo-env-android
文档版本：V1.0
目标平台：Android（Android 8.0+，arm64为主）
内核方案：GeckoView（Mozilla Gecko 嵌入式Firefox内核）
产品定位：面向研发、测试工程师的安卓端隔离指纹环境浏览器工具；独立项目，与PC端FinEnv解耦。

## 1 概述
### 1.1 产品背景
移动端H5页面测试缺少稳定、指纹可控、多账号隔离的浏览器工具。市面安卓WebView类隔离工具受系统WebView版本、厂商魔改影响大，指纹一致性差。
本项目基于GeckoView实现，自带独立Firefox内核，不受手机系统浏览器内核约束，每个测试账号对应一套独立隔离浏览器环境，Cookie、LocalStorage、缓存、指纹配置完全隔离，支持指纹快照、代理、Marionette自动化，用于移动端H5兼容性测试、业务页面多账号测试。

> 重要边界：安卓平台底层限制，本项目为App内多GeckoView实例隔离，**不是独立操作系统进程隔离**，隔离等级弱于PC独立Chromium进程方案。

### 1.2 适用范围
✅ 包含：多环境管理、账号台账、指纹参数配置、指纹快照、代理配置、Marionette自动化接口、审计日志、主题自定义、环境导入导出
❌ 不包含：Root模式独立进程拉起、内核源码深度定制、对抗黑产场景、上架应用商店（内部工具，企业内部分发）

### 1.3 用户角色
- 测试工程师：多账号轮换测试H5业务、复现线上Bug、保存测试环境快照
- 前端开发：移动端多UA/多指纹调试页面、兼容性验证
- 自动化脚本开发：通过Marionette协议驱动环境执行自动化用例

## 2 业务需求
1. 一个环境对应独立GeckoView实例 + 独立Profile目录，环境之间存储、缓存、Cookie完全隔离，互不污染。
2. 环境关闭、App重启后，登录状态、缓存、指纹配置持久保留。
3. 支持保存指纹快照，一键还原整套指纹参数，用于复现Bug。
4. 每个环境支持独立代理配置（HTTP/SOCKS5）。
5. 对外提供Marionette协议接入，支持外部自动化脚本控制页面、截图、读写Cookie。
6. 支持批量导入/导出加密环境包，测试人员之间同步测试环境。
7. 内置审计日志，记录环境启停、指纹修改、代理变更、快照操作。

## 3 功能需求
### 3.1 环境管理（P0）
1. 新建环境，自动分配独立Profile目录，自动生成一套默认自洽指纹。
2. 环境列表：名称、分组、状态、绑定账号、代理状态、内核版本。
3. 分组+标签管理：项目名称、测试环境（dev/test/prod）、版本标记、用例备注，支持搜索筛选。
4. 环境克隆、删除、批量导出加密包、导入加密包。
5. 环境开关：打开/关闭浏览器实例；支持后台保活（受安卓系统电源策略限制）。

### 3.2 账号台账（P0）
每条环境绑定一条账号记录：账号、备注、负责人、密码（加密存储）、状态【待启用 / 使用中 / 冻结】。
密码、敏感信息落盘加密，不存储明文。

### 3.3 指纹配置（P0）
可配置指纹参数：
UA、屏幕分辨率、设备型号、时区、语言、Canvas指纹、WebGL指纹、Audio指纹、WebRTC配置、插件列表、客户端Hint。
内置指纹一致性校验，禁止冲突参数；内置指纹检测能力，一键生成指纹检测报告。

### 3.4 代理管理（P0）
1. 单环境独立代理，支持HTTP、HTTPS、SOCKS5代理。
2. 代理连通性检测，检测失败标记告警。
3. 代理池管理，批量给环境分配代理。

### 3.5 Marionette自动化（P0，差异化重点）
1. 每个打开的GeckoView实例启动独立Marionette服务，独占端口。
2. 支持外部Python/JS Marionette客户端连接，页面导航、截图、执行JS、读写Cookie、获取页面元素。
3. 可开关Marionette服务，支持端口自定义。

### 3.6 存储与加密（P0）
1. 所有配置、账号密码、快照信息，在App私有数据库加密存储。
2. 环境导出包整体AES256加密，导入需要密钥。
3. 本地自动备份全部环境配置。

### 3.7 审计日志（P1）
记录：操作时间、环境ID、操作人、操作类型（新建/打开/关闭/修改指纹/切换代理/快照）、备注；日志只追加，不可删除，支持导出csv。

### 3.8 UI主题自定义（P1）
1. 亮色 / 暗色 / 跟随系统
2. 自定义主色，HEX取色、颜色选择器
3. 布局密度：紧凑 / 宽松
4. 主题配置导出、导入
> 主题仅作用GeoEnv管理面板，**不影响GeckoView浏览器页面渲染与指纹**

### 3.9 辅助测试能力（P1）
1. 单环境独立Hosts劫持
2. HAR抓包录制、导出
3. 弹窗验证码聚合面板，汇总所有打开环境弹窗

## 4 非功能需求
1. 性能：单GeckoView实例启动≤3s；受GeckoView内存开销限制，建议并发上限≤5个环境
2. 兼容性：最低Android 8.0，优先arm64-v8a；支持Android 13/14/15
3. 安全：敏感数据AES256加密；Marionette端口仅本地回环访问，禁止外网暴露
4. 稳定性：Gecko版本锁定，固定版本打包，避免版本变动导致Marionette、指纹Hook失效
5. 分发：支持内部apk、aab，支持离线部署，不需要应用商店上架

## 5 版本迭代规划
- V0 原型：GeckoView多实例隔离、基础环境CRUD、基础指纹配置、Marionette打通
- V1.0 正式版：账号台账、代理池、指纹快照、加密导入导出、主题系统、审计日志
- V1.1：HAR抓包、Hosts劫持、批量操作、自动化SDK封装
- V1.2：权限管理、远程同步加密环境包

## 6 验收标准
1. 多个GeckoView环境登录不同账号，Cookie、LocalStorage互相隔离，互不串号
2. App完全关闭重启，所有环境配置、登录状态保留
3. Marionette客户端可成功连接对应环境，执行页面操作、截图
4. 修改主题颜色，保存后重启App配置不丢失
5. 导出的加密环境包，可在另一台设备导入恢复完整环境
6. 数据库内账号密码、敏感配置无明文存储
